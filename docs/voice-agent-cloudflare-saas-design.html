1Cloudflare 不是只有靜態網頁

Workers 本身就是後端。前面看到的語音驗證、收單、記憶存取，全部都是跑在 Workers 上的後端邏輯，不是靜態頁面能做的事。

3一句話

不用另外找地方架 Server，Workers 就是 Server。做 SaaS 需要的只是在現有這些模組裡，每個地方都多帶一個「這是哪個客戶」的標籤，不是換一套技術。
