# voice-agent 詞彙表

| 詞彙 | 白話定義 |
|---|---|
| LIFF | 在 LINE 裡打開的網頁；可以取得 LINE 使用者身分。 |
| `lineUserId` | LINE 用來辨識同一個人的穩定 ID；文字、語音、記憶要靠它接在一起。 |
| Realtime | 低延遲即時語音連線；需要維持較長的音訊連線。 |
| Chat Completions | 一問一答的文字模型呼叫；不用維持即時語音連線。 |
| function calling | AI 要執行程式動作時，呼叫後端定義好的工具。 |
| memory | 關於某個人的可長期使用資訊，例如偏好或聯絡資料。 |
| knowledge base | 可搜尋的文件或歷史內容；不等於個人記憶。 |
| connector | 把整理後的內容送到 email、記帳系統或其他 AI 的出口。 |
| provider | 提供 AI 能力的服務，例如 xAI 或 OpenAI。 |
| adapter | 把不同 provider 的差異包起來，讓上層使用同一個介面。 |
