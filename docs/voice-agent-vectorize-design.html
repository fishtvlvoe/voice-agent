Vectorize 知識庫模組設計

怎麼把「向量搜尋」這塊接進 Cloudflare 架構

1先講清楚 Vectorize 的角色

Vectorize 只做一件事：拿一段文字的向量，找出資料庫裡最相近的其他向量。它不存原文、不會關鍵字比對。這兩件事要另外接。

2開一個獨立的索引，跟現有的分開

現有CATEGORY_INDEX：比對固定類別清單用，資料很少變動
新增KNOWLEDGE_INDEX：知識庫問答用，內容會持續新增/更新
分開的原因：用途不同、metadata 格式不同，以後要重建其中一個索引時不會互相干擾。

5一開始就要定死、事後改不了的事

  • 建索引時要先指定「向量維度」，要跟選用模型輸出的維度一致（bge-m3 固定輸出一種維度）
  • 中途想換模型 → 新模型輸出維度通常不同 → 舊向量全部作廢，要整個重新跑一次「文件進來」那條路徑重建
  • 所以模型選定後盡量不要中途換，除非有心理準備要重建
