# UI/UX 設計規格（voice-agent 全域適用）

> 這份文件放全專案通用的介面設計規則，不綁單一 SR。之後任何 LIFF 介面、Rich Menu、mockup 都要遵守，不用每次重講。

## 產品名稱（2026-09-23 定）

- **正式名稱：aiver AI智慧助理**（不要再用「LINE 語音助理」這個稱呼）
- 之後所有介面文案、Rich Menu、文件標題都要換成這個名字
- **xAI Agent 名稱：Aiver**（簡短版，不用打全名）
- **LINE Channel / 官方帳號名稱：AIVER AI 語音助理**（2026-09-23 定，全新一組，跟舊有的「AIver」LINE Login channel（Provider 華AI 底下，Published，連結 AI 小華官方帳號）完全無關，不可重用/改動那組）

## Icon 規則（2026-09-23 定）

- **一律用 SVG 圖示，禁止用 emoji 當 icon**（🎙 📋 ❓ 這類不可再出現在正式介面或 mockup 裡）
- SVG 來源：優先用 [Lucide](https://lucide.dev/) 或專案已引入的 icon 套件，風格統一 line-style（線條式，非填色）
- 尺寸/顏色跟隨當下元件的 `currentColor`，方便套用主題色（LINE 綠 `#06C755`）
- 佔位/草稿階段也要用 SVG，不可用 emoji 先頂著
